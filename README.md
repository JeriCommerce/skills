# JeriCommerce Skills

Installable AI coding skills for JeriCommerce integrations.

## Install

```bash
# List available skills
npx skills add jericommerce/skills --list

# Install a specific skill
npx skills add jericommerce/skills --skill loyalty-template-creator

# Install all skills
npx skills add jericommerce/skills --all

# Update installed skills
npx skills update
```

## Available Skills

| Skill | Description |
|-------|-------------|
| **loyalty-template-creator** | Create CDN loyalty page templates for Shopify theme extensions by replicating the visual style of a reference website |
